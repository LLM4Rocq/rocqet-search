Rocqet's own code (`rocqet/`, `web/`, `scripts/`) is licensed under
[Apache 2.0](LICENSE).

The **indexed dataset** (`deploy/declarations.enriched.jsonl`, distributed as
a GitHub Release asset, not committed to this repo) is a different matter: it
embeds verbatim excerpts — `name`, `type_signature`, `statement`,
`docstring` — extracted directly from each library's source `.v` files.
Those excerpts remain under their original library's license, not Apache
2.0:

| Library | License | Source |
|---|---|---|
| stdlib | LGPL 2.1 | [rocq-prover/stdlib](https://github.com/rocq-prover/stdlib) |
| mathcomp | CeCILL-B | [math-comp/math-comp](https://github.com/math-comp/math-comp) |
| mathcomp-analysis | CeCILL-B | [math-comp/analysis](https://github.com/math-comp/analysis) |
| GeoCoq | LGPL 3 | [GeoCoq/GeoCoq](https://github.com/GeoCoq/GeoCoq) |

The natural-language descriptions (`nl_description`) attached to each
declaration are not present in any upstream library license. For stdlib,
mathcomp-analysis, and GeoCoq they're generated by Rocqet
(`rocqet.describe`). For **mathcomp**, they come from a separate project,
not Rocqet:

- **[LLM4Docq](https://github.com/LLM4Rocq/LLM4Docq-MathComp)** (MIT
  license), primarily by [theostos](https://github.com/theostos) —
  LLM-generated docstrings with expert review, an iterative
  annotate/regenerate process. Dataset:
  [theostos/llm4docq-mathcomp](https://huggingface.co/datasets/theostos/llm4docq-mathcomp)
  on Hugging Face. Rocqet joins this data in by declaration name
  (`scripts/attach_mathcomp_nl.py`) rather than generating it.

If you redistribute the dataset (not just the Rocqet codebase), you are
redistributing content under these upstream licenses and are responsible for
complying with their terms — CeCILL-B and LGPL both require preserving
license notices and, for LGPL, additional conditions if you modify the
covered code itself. Check each license's text before republishing the
dataset standalone (e.g. as a Hugging Face dataset).
